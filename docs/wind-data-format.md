# 风场数据格式规范

## 概述

风场数据采用 JSON 格式，包含两个分量（U 和 V），用于渲染颜色图层、粒子图层、箭头图层和风杆图层。

## 数据结构

```json
[
  {
    "header": {
      /* U分量头信息 */
    },
    "data": [
      /* U分量数据数组 */
    ]
  },
  {
    "header": {
      /* V分量头信息 */
    },
    "data": [
      /* V分量数据数组 */
    ]
  }
]
```

## Header 字段说明

### 必需字段

| 字段名              | 类型   | 说明                                         | 示例值       |
| ------------------- | ------ | -------------------------------------------- | ------------ |
| `parameterCategory` | Number | 参数类别，风场固定为 2                       | `2`          |
| `parameterNumber`   | Number | 参数编号，**U 分量必须为 2，V 分量必须为 3** | `2` 或 `3`   |
| `nx`                | Number | 经度方向网格点数                             | `758`        |
| `ny`                | Number | 纬度方向网格点数                             | `518`        |
| `lo1`               | Number | 起始经度（左边界）                           | `115.515259` |
| `lo2`               | Number | 结束经度（右边界）                           | `123.090256` |
| `la1`               | Number | 起始纬度（上边界，北纬为正）                 | `27.85503`   |
| `la2`               | Number | 结束纬度（下边界）                           | `22.680031`  |
| `dx`                | Number | 经度方向网格间距（度）                       | `0.01`       |
| `dy`                | Number | 纬度方向网格间距（度）                       | `0.01`       |

### 可选字段

| 字段名                  | 类型   | 说明                                     | 示例值                  |
| ----------------------- | ------ | ---------------------------------------- | ----------------------- |
| `refTime`               | String | 参考时间（数据生成时间）                 | `"2026-01-22 00:00:00"` |
| `begTime`               | String | 数据起始时间                             | `"2026-01-22 00:00:00"` |
| `parameterCategoryName` | String | 参数类别名称                             | `"nc"`                  |
| `parameterNumberName`   | String | 参数编号名称，U 分量为 u10，V 分量为 v10 | `"u10"` 或 `"v10"`      |
| `numberPoints`          | Number | 数据点总数（应等于 nx × ny）             | `392644`                |
| `basicAngle`            | Number | 基本角度                                 | `0`                     |
| `scaleVal`              | Number | 缩放值                                   | `1`                     |
| `addVal`                | Number | 偏移值                                   | `12.895647`             |

## Data 字段说明

- 类型：`Number[]`（一维数组）
- 长度：必须等于 `nx × ny`
- 排列顺序：从左上角开始，按行优先排列（先经度后纬度）
- 单位：m/s（米/秒）

```
数据索引 = j * nx + i
其中：
  i = 经度方向索引 (0 到 nx-1)
  j = 纬度方向索引 (0 到 ny-1)
```

## 关键规则

### 1. parameterNumber 必须正确

粒子图层通过 `parameterCategory,parameterNumber` 组合识别分量：

| 组合  | 含义                               |
| ----- | ---------------------------------- |
| `2,2` | U 分量（东西方向风速，正值为东风） |
| `2,3` | V 分量（南北方向风速，正值为北风） |

**如果两个分量的 parameterNumber 相同，粒子图层将无法正常工作！**

### 2. 网格参数必须一致

U 分量和 V 分量的以下参数必须完全相同：

- `nx`, `ny`（网格尺寸）
- `lo1`, `lo2`, `la1`, `la2`（边界范围）
- `dx`, `dy`（网格间距）

### 3. 数据长度校验

```
data.length === nx × ny
```

### 4. 坐标系统

- 经度：东经为正，西经为负
- 纬度：北纬为正，南纬为负
- 扫描模式：从左上角(lo1, la1)开始，向右向下扫描

## 风速计算

风速（标量）由 U 和 V 分量计算：

```javascript
windSpeed = Math.sqrt(u * u + v * v);
```

风向（角度）计算：

```javascript
windDirection = (Math.atan2(u, v) * 180) / Math.PI;
```
