# 海洋 GIS 风浪流方向基础笔记

## 1. 风浪流是什么

海洋 GIS 中常说的“风浪流”，通常指海洋环境里的三类时空场数据：

- 风：海面上方空气怎么运动。
- 浪：海面波动有多高、从哪里来、往哪里传播。
- 流：海水本身往哪里流、流得多快。

它们都和时间、空间位置有关，所以在系统里经常表现为某个时刻、某个经纬度网格上的数值。例如风速、风向、波高、波向、流速、流向等。

## 2. “风来、浪来、流去”是什么意思

“风来、浪来、流去”说的是风、浪、流的方向字段含义不完全一样：

- 风向：通常表示风从哪里吹来。
- 浪向：通常表示浪从哪里传来。
- 流向：通常表示水流往哪里流去。

也就是说，风和浪的方向多是“来向”，流的方向多是“去向”。

这是海洋 GIS 显示里非常容易混淆的点。如果不区分“来向”和“去向”，地图上的箭头可能会反着画。

## 3. 方向角的常见约定

海洋、气象数据里方向角通常按下面方式理解：

- 0 度：北
- 90 度：东
- 180 度：南
- 270 度：西

角度一般是从北方向开始，顺时针增加。

注意：这是业务方向角，不完全等同于数学坐标系里的角度。数学里常见的是 0 度朝东，逆时针为正；海洋气象方向角通常是 0 度朝北，顺时针为正。

## 4. 同一个方向值在风、浪、流里的差异

假设某个数据点的方向值是 90 度：

| 类型 | 字段含义 | 实际运动方向 | GIS 箭头如果表示运动方向 |
| --- | --- | --- | --- |
| 风向 90 度 | 风从东边来 | 向西吹 | 箭头指向西 |
| 浪向 90 度 | 浪从东边来 | 向西传播 | 箭头指向西 |
| 流向 90 度 | 水往东边流 | 向东流 | 箭头指向东 |

所以：

- 风向、浪向如果是“来向”，要转成运动方向时通常需要加 180 度。
- 流向如果本来就是“去向”，显示运动箭头时通常直接使用。

## 5. 风向、浪向、流向的例子

### 东风

“东风”不是吹向东方，而是从东方吹来。

- 风向：90 度
- 实际运动：从东向西
- 如果画风粒子或箭头：应该向西运动

### 东浪

如果浪向定义为“来向”，东浪表示浪从东方来。

- 浪向：90 度
- 实际传播：从东向西
- 如果画传播箭头：应该向西

### 向东流

流向通常表示“去向”，向东流就是水往东流。

- 流向：90 度
- 实际运动：向东
- 如果画流场箭头：应该向东

## 6. u/v 分量是什么

很多模型数据不会只给方向和速度，而是给两个分量：

- u：东西向分量，正值通常表示向东。
- v：南北向分量，正值通常表示向北。

风、流很常见这种形式。浪有时也会有方向、周期、波高等字段，而不是直接给 u/v。

通过 u/v 可以计算速度大小：

```text
speed = sqrt(u * u + v * v)
```

也可以反算运动方向。注意这个方向通常是“去向”，因为 u/v 描述的是实际运动矢量。

## 7. GIS 显示时要先问清楚的问题

拿到客户文件后，不要只看字段名就直接画。建议先确认：

1. 方向字段是“来向”还是“去向”？
2. 角度是否是 0 度为北、顺时针增加？
3. 风、浪、流三个方向字段是否使用同一套约定？
4. 如果同时有方向和 u/v，二者能不能对得上？
5. 前端箭头要表达的是“来源方向”还是“实际运动方向”？

其中第 5 点很重要。业务用户看图时，通常更直观的是实际运动方向：风往哪吹、浪往哪传、水往哪流。

## 8. 前端绘制的常用处理规则

如果要在地图上画表示运动方向的箭头，可以先按下面规则处理：

```text
风运动方向 = 风向 + 180 度
浪传播方向 = 浪向 + 180 度
流运动方向 = 流向
```

为了避免超过 360 度，通常会做一次取模：

```text
direction = (direction + 360) % 360
```

例如：

```text
风向 90 度：
风运动方向 = (90 + 180) % 360 = 270 度
表示向西

流向 90 度：
流运动方向 = 90 度
表示向东
```

## 9. 容易踩坑的地方

- 把风向理解成“吹向哪里”，导致风箭头反向。
- 把浪向理解成“传向哪里”，导致浪箭头反向。
- 风、浪、流都用同一个旋转规则，导致流向被反转。
- 忽略不同数据源的定义差异。并不是所有数据都一定遵守同一套约定。
- 忽略地图图标自身的默认朝向。例如图标默认朝上还是朝右，会影响旋转角度。

## 10. 一个实用判断方法

如果客户文件同时提供方向和 u/v 分量，可以用一个样例点交叉验证：

- 如果 u 为正、v 接近 0，说明实际运动大致向东。
- 对流来说，流向应该接近 90 度。
- 对风来说，如果风实际向东吹，那么风向来向应该接近 270 度，也就是从西边来。

通过这种方式可以判断字段到底是“来向”还是“去向”。

## 11. 简短记忆

记住一句话：

```text
风从哪来，浪从哪来，流往哪去。
```

如果地图箭头要画实际运动方向：

```text
风、浪反一下，流不反。
```
