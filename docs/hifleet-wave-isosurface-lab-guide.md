## 一、背景与定位

全球海洋气象（如 ECMWF、GFS、WW3 等模型）预报数据通常以离散格点场（GRIB / NetCDF）形式发布。前端在可视化海浪有效波高（Significant Wave Height, Hs）时，面临四大核心挑战：
1. **渲染卡顿**：全球等值面包含数千个复杂闭合多边形（Polygon / MultiPolygon）、数十万个坐标点，传统 SVG 节点注入会导致页面严重掉帧乃至崩溃；
2. **边缘走样与锯齿**：网格线性插值生成的等值面在拐角处呈 90° 或锯齿折线，视觉粗糙；
3. **陆地溢出穿模**：数学插值算法不感知大陆海岸线，海浪色块大面积溢出覆盖到大陆、岛屿和陆地湖泊内部；
4. **跨日界线断裂**：Leaflet 地图在连续横向拖动（经度超过 $\pm 180^\circ$）时，几何要素在世界副本（World Copies）出现截断空白。

本实验室完整对标国际主流专业航运系统 **HiFleet（船队在线）** 的可视化流水线，彻底解决上述难题。

## 二、目标网站 (HiFleet) 核心技术逆向解析

### 2.1 气象接口与数据格式

- **数据请求 URL 示例**：
  ```http
  https://w1.hifleet.com/hfWeatherApi/getWaveIsosurface3583?&type=ecmwf&time=20260908&f=204
  ```
- **数据结构**：
  返回标准的 GeoJSON `FeatureCollection`，包含 370~1500 个要素：
  ```json
  {
    "type": "FeatureCollection",
    "features": [
      {
        "type": "Feature",
        "properties": {
          "hvalue": 3.5,
          "color": "#4da6ff",
          "fillColor": "#4da6ff"
        },
        "geometry": {
          "type": "Polygon",
          "coordinates": [[[lng, lat], [lng, lat], ...]]
        }
      }
    ]
  }
  ```
- **关键特征**：
  - 后端返回的数据中**已经带有业务波高等级颜色**（`color`），无需前端硬编码色板；
  - 几何要素是由网格生成的等值线环围成的多边形，包含外环与打洞内环（Holes）；
  - **原始数据本身带有折线拐角**，并非天上就是完全平滑的曲线。

### 2.2 官方平滑算法真相 (Chaikin 3 轮迭代)

通过对 HiFleet 生产环境构建脚本（`app.js`，内部模块编号 `b84a`）的逆向工程分析，查明了其平滑处理的真实逻辑：

```javascript
// HiFleet 逆向提取代码片段 (模块 b84a)
var turfPolygonSmooth = require("@turf/polygon-smooth");
...
var smoothedData = turfPolygonSmooth(rawGeoJson, { iterations: 3 });
```

#### 算法本质：Chaikin's Corner Cutting Algorithm（蔡金割角平滑算法）
- **核心逻辑**：
  对于环形闭合折线上的相邻点 $P_i$ 与 $P_{i+1}$，割掉尖锐拐角，在每条线段的 $1/4$ 和 $3/4$ 处插入两个新点：
  $$Q_i = \frac{3}{4} P_i + \frac{1}{4} P_{i+1}$$
  $$R_i = \frac{1}{4} P_i + \frac{3}{4} P_{i+1}$$
- **迭代次数对比**：
  | 迭代轮数 | 顶点增量 | 单帧计算耗时 | 视觉形态 |
  | :--- | :--- | :--- | :--- |
  | **0次 (未平滑)** | 1x (原始点) | 0ms | 原始网格直角折线，微观有折角 |
  | **1次 (轻度)** | 2x | ~2ms | 消除 90° 尖锐直角，转为平滑倒角 |
  | **2次 (适度)** | 4x | ~6ms | 割角更细腻，过渡柔顺 |
  | **3次 (HiFleet标配)** | 8x | ~22ms | **完全对标 HiFleet 官方曲线**，饱满圆润且运算极轻 |

> **关键技术事实**：由于 HiFleet 单帧要素数约 370 个，3 轮 Chaikin 迭代在现代浏览器 V8 引擎中仅消耗 **~22ms**，完全在主线程安全预算（$\le 50\text{ms}$）以内，无需 Web Worker 也能保证界面绝对无顿挫。

#### 本系统高性能演进：Float64Array 连续内存优化 (方案 1)
为了进一步榨干算力、彻底根除小数组分配带来的 GC 停顿，本系统在工程实现上进行了连续内存重构：
- 引入模块级复用双缓冲 `_chaikinBufA` 与 `_chaikinBufB`（`Float64Array`）；
- 中间多轮细分迭代完全在扁平的 `[x0, y0, x1, y1...]` 连续内存中执行 Ping-Pong 向量乘加，实现 **Zero-GC 零中间对象分配**；
- 实测 3 轮割角平滑耗时从原本的 7~22ms 骤降至 **2~4ms**，即使在 1500+ 个要素的海量数据下也能瞬间完成。

### 2.3 陆地防溢出黑科技：陆地掩膜瓦片 (Land Mask Tiles)

气象等值面在数学插值计算时，是把地球当成一个均匀球体进行连续场拟合，因此多边形必然会穿透大陆与海岸线。

#### 为什么不用前端几何拓扑裁剪？
传统 GIS 思路是用陆地多边形（如全球 1:1000 万海岸线）对海浪要素执行空间求差（`turf.difference` 或 Clipper 算法）。然而，面对 40 万顶点的全球海浪图元，**空间拓扑求差会让浏览器主线程直接假死卡死 3~5 秒**，在移动端更会导致内存溢出崩溃。

#### HiFleet 的视觉掩膜方案（Visual Masking）
HiFleet 采用了一种架构级的软解法：**引入专门渲染陆地的定制切片服务**。
- **瓦片服务地址**：
  - 白昼浅色陆地：`https://static.hifleet.com/hfWeatherWaveApi/hlandmap/{z}/{x}/{y}.png`
  - 暗夜深色陆地：`https://static.hifleet.com/hfWeatherWaveApi/darklandmap/{z}/{x}/{y}.png`
- **瓦片 Alpha 通道特征**：
  - **海洋区域**：RGBA 的 Alpha 为 0（**100% 完全透明**）；
  - **陆地与岛屿**：Alpha 为 1（**实体不透明纯色**，`#D2D2D2` 或暗深色）。
- **Leaflet 层级拓扑架构**：
  ```
  [Top]    Layer 3: 陆地掩膜瓦片 (landMaskPane, zIndex: 450) -> 扣在上方，裁切所有陆地溢出色块
  [Middle] Layer 2: 海浪等值面图层 (wavePane,     zIndex: 420) -> Canvas 全局硬件加速绘制
  [Bottom] Layer 1: 底图瓦片       (tilePane,     zIndex: 200) -> 卫星底图 / 海图 / 暗色底图
  ```
- **核心收益**：
  **0 毫秒几何计算耗时**，完全依赖 GPU 纹理混合管线，在瞬间完成精准的海岸线裁切！

### 2.4 全球无缝环绕 (Anti-Meridian 跨日界线处理)

- **问题根因**：
  ECMWF 经度坐标为 $[0^\circ, 360^\circ]$ 或 $[-180^\circ, 180^\circ]$。Leaflet 地图在缩放到全球级别（Zoom 1~3）横向滚屏时，如果用户拖到太平洋东侧或大西洋，会产生新的投影世界副本（World Copy）。如果不做处理，海浪图层会在 $180^\circ$ 经线处生硬截断，周围副本全为空白。
- **解决方案 (`buildMultiWorldGeoJson`)**：
  在渲染前，将 FeatureCollection 沿经度方向克隆平移 `[-360, 0, 360]`：
  $$\text{Coordinates}_{\text{shifted}} = [\text{lng} + \text{offset}, \text{lat}]$$
  一次性合并为三倍经度跨度的 MultiWorld 几何，实现向左、向右无限横向漫游无缝显示。

### 2.5 真实生产环境时间轴机制

在实际业务生产环境中，系统界面下方通常是一个气象预报**时间轴播放条（Timeline Bar）**：
- 每次播放推进一步（如从 `08:00` 推进到 `11:00`），系统收到的是**对应时刻的全新一帧数据**；
- 生产环境不会在固定的两三份数据之间来回死循环切换，因此**每一帧到达时都必须进行实时的解析、经度平移、平滑割角与 Canvas 绘制**；
- 如果测试环境默认开启强缓存复用，将无法真实衡量时间轴连续播放时的性能瓶颈。因此在实验室中，**缓存开关默认必须保持关闭**。

### 3.4 测试数据源切换与缓存开关 (默认关闭)

- **功能位置**：右侧面板「测试数据源切换」。
- **预置测试数据集**：
  1. `2026-09-07 20:00 (ECMWF全球)`：全球网格，468 个要素；
  2. `2026-09-08 20:00 (ECMWF全球)`：全球网格，363 个要素；
  3. `HiFleet 真实 20260908 (f204)`：**HiFleet 线上抓取的真实等值面数据**，370 个要素。
- **「开启缓存」开关（默认关闭）**：
  - **默认关闭状态 (`enableCache: false`)**：
    - **完全对标真实时间轴播放场景**；
    - 禁用图层实例缓存（`layerCache`）与后台静默预热；
    - 每次点击切换数据集，均强制执行完整管线：注销旧图层 $\rightarrow$ 经度跨界平移 $\rightarrow$ Chaikin 割角平滑 $\rightarrow$ 实例化 Canvas 图元 $\rightarrow$ 绘制上屏；
    - 保证开发者能真实测出每一帧数据到达时的真实前端渲染吞吐量。
  - **开启缓存状态 (`enableCache: true`)**：
    - 将生成的图层实例常驻于 `layerCache` 中；
    - 切回已访问过的数据集时，直接执行 `cachedLayer.addTo(map)`，**耗时仅 0~2ms，实现瞬间切帧**；
    - 自动激活 `requestIdleCallback`，利用浏览器空闲时段静默在后台预热构建尚未点击的相邻数据集。

### 3.6 空间属性拾取 (Hover / Click Popup)
- **底层原理**：
  由于 Canvas 硬件加速图层配置了 `interactive: false`（避免上千个 DOM 节点监听造成卡顿），页面采用**纯内存空间射线投射算法（Ray-Casting Point-in-Polygon）**：
  1. **外接矩形快速初筛（BBox Pruning）**：先比较点击坐标点是否在要素的外接矩形内，剔除 98% 以上不相关的多边形；
  2. **射线法精准相交（PIP Ray-Casting）**：对候选要素的内外环顶点进行从左至右的射线穿透求交，奇数次相交即为命中；
  3. **30ms 节流悬浮感知**：鼠标划过海面时，右侧面板在 30ms 节流下实时更新「当前悬浮点波高」、「标示颜色」与「经纬坐标方位」；
  4. **点击弹出气泡 (Popup)**：点击任意海面点，弹出对齐专业气象样式的 Leaflet Popup，显示数值与十六进制颜色码。

## 四、核心技术选型与架构权衡 (Trade-offs)

| 架构维度 | 传统常见选型 (已废弃) | 本系统选型 (HiFleet 标配) | 选型权衡原因 (Trade-offs) |
| :--- | :--- | :--- | :--- |
| **几何渲染器** | Leaflet 默认 SVG (`L.geoJSON`) | 全局 Canvas (`L.canvas({ pane: "wavePane" })`) | **DOM 压力与帧率权衡**：SVG 会产生 1500+ 个 DOM 节点，拖动地图卡顿 1.5s；Canvas 全局仅 1 个画布，绘制仅需 30ms，拖动 60fps。 |
| **瓦片切片引擎** | 矢量瓦片切片 (VectorGrid) | 全局矢量 GeoJSON (`smoothFactor: 0`) | **保真度权衡**：切片会导致同心圆环波浪被硬生生切断、抽稀走样；原生 GeoJSON 保证圆环绝对无损无缝。 |
| **平滑算法** | Bézier 贝塞尔曲线拟合 | Chaikin 割角平滑算法 (`iterations: 1~3`) | **算力与自相交权衡**：三次贝塞尔样条在复杂自相交多边形上极易产生回环畸变与卡死；Chaikin 算法数学稳定、绝不自相交、计算极速。 |
| **陆地防穿模** | 前端空间几何拓扑裁剪 (`turf.difference`) | 视觉掩膜切片 (`hlandmap` 扣盖) | **CPU 算力与 GPU 混合权衡**：多边形拓扑差集在前端需 3~5 秒计算且极易崩溃；切片遮挡依靠 GPU 纹理管线 0ms 瞬间遮挡。 |
| **空间交互事件** | 图层内置 DOM 点击事件 (`interactive: true`) | 内存射线法碰撞代理 (`interactive: false`) | **内存与垃圾回收权衡**：避免成千上万个几何对象挂接事件监听器导致的内存泄漏，由空间索引 + 射线法毫秒级计算。 |
| **时间轴缓存机制** | 强缓存所有图层实例 | 缓存可配置 (默认关闭模拟实时流水线) | **真实业务对齐权衡**：真实时间轴每帧均为新数据，默认关闭缓存能真实评估管线瓶颈，保留开关用于特定对比。 |
